# Registro licenze degli asset di terzi

Per ora ASTRA è privato, quindi ogni licenza è accettabile. Questo registro esiste per un'eventuale pubblicazione futura: dice esattamente cosa va sostituito o accreditato.

**Segnalazioni:** `NC` = solo uso non commerciale · `PERSONAL` = solo uso personale · `NOAI` = vietato l'uso per addestrare AI · `UEONLY` = utilizzabile solo in Unreal · `ATTR` = attribuzione obbligatoria.

Il registro completo, riga per riga, è in [licenze.csv](licenze.csv) (aggiornato automaticamente dagli script di acquisizione).

| Fonte | Licenza tipica | Note |
|---|---|---|
| Poly Haven, ambientCG, 3dtextures.me, ShareTextures | CC0 | nessun obbligo |
| Blendkit | CC0 / Royalty-Free | RF: vietato ridistribuire l'asset "grezzo" |
| Sketchfab | per modello (CC0, BY, BY-NC…) | `ATTR` su BY, `NC` su BY-NC |
| NASA (3D, SVS, immagini) | pubblico dominio | niente loghi NASA, niente endorsement; credito "NASA/GSFC SVS" per le mappe SVS |
